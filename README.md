# Bean Scene Coffee Shop

Адаптивний frontend лендингу за
[макетом Bean Scene у Figma](https://www.figma.com/design/njfrGre0pKcv2CPjBfUzrk/Bean-Scene-Coffee-Landingpage--Community-?node-id=1-4)
та ТЗ Coffee Shop.

## Запуск

Потрібен Node.js 24. Шрифти й зображення зберігаються локально; сторонні сервіси
для роботи сторінки не потрібні.

```sh
npm ci
npm run dev
```

Vite виведе адресу локального сервера. Production-збірка:

```sh
npm run build
npm run preview
```

## Структура та реалізація

- `src/index.html` — семантичний каркас.
- `src/partials/` — header, hero, about, menu, features, promotion,
  testimonials, footer, мобільне меню та модальна форма.
- `src/css/index.css` — вхід стилів, modern-normalize та локальні шрифти
  Playfair Display / Clicker Script.
- `src/css/*.css` — стилі секцій, mobile-first; `modal.module.css` — ізольовані
  CSS Modules для модального вікна.
- `src/main.ts` — TypeScript: меню, діалог, валідація форм, демовідгуки.
- `src/img/` — оригінальна графіка Figma, оптимізована у WebP, SVG та спрайт
  нових іконок `icons.svg`.
- `tests/` — браузерні перевірки Playwright та axe.

Мобільна верстка гумова від 320 px, контейнер обмежений 375 px. Від 768 px —
планшетна композиція, від 1440 px — desktop із контейнером 1180 px. Мобільного
макета у Figma немає, тому ці стани спроєктовані в коді. Кольори, оригінальні
зображення та desktop-композиція збережені. Тексти Sign Up, Subscribe, Espresso
й очевидні граматичні помилки виправлені.

## Взаємодія

- Навігація веде до секцій; Learn More — до переваг.
- Order Now і Join Us відкривають форму заявки; кнопка картки обирає відповідний
  напій.
- Меню та backdrop відкриваються класом `is-open`.
- Є закриття через кнопку, Escape, клік по backdrop; утримання та повернення
  фокусу, блокування прокрутки й `inert` для фону.
- Підписка та заявка перевіряють введення, але **нічого не відправляють і не
  зберігають**. Повідомлення про це показане до та після відправлення.
- Акаунти, соцмережі та відсутні сторінки — неактивні заглушки з
  `aria-disabled`.
- Відгуки написані для демонстрації й явно так позначені. Ім'я, посада та
  портрет взяті з макета; це не підтверджені відгуки клієнта.
- Контакти й склад напоїв перенесені з макета, не є перевіреною інформацією
  реального бізнесу.

## Зображення

Контентні растрові зображення мають `srcset` 1×/2×, фонові —
`min-resolution: 2dppx`. Оригінальні SVG використані без перемальовування. Нові
іконки форм — у спрайті. Усі URL ресурсів локальні, тимчасових посилань Figma в
застосунку немає.

`docs/image-manifest.json` фіксує розміри та вагу кожного WebP. Деякі джерела
Figma (hero, footer, фон, чашки, портрет і фото About) менші за повний 2×.
Варіанти 2× згенеровані з доступних оригіналів; інтерполяція не додає
фотографічних деталей. Для справжньої додаткової деталізації потрібні оригінали
більшої роздільності.

Повторна оптимізація з локального каталогу оригіналів:

```sh
node scripts/prepare-images.mjs <original-assets-directory>
```

## Перевірки

```sh
npm run typecheck
npm run format:check
npm run build
npx playwright install chromium
npm test
```

Тести перевіряють переповнення на 320/375/767/768/1024/1366/1440/1920 px,
локальні ресурси, доступність, меню, модальні вікна, фокус, форми, карусель та
2×. Скріншоти записуються в ігнорований `test-results/`. Форматування:
`npm run format`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` використовує Node.js 24, `npm ci`,
перевірки та build; публікує `dist` у гілку `gh-pages`. Шлях збірки —
`/Coffee-Shop-Landingpage/`.

У Settings → Pages: Deploy from a branch → gh-pages → / (root). Очікувана
адреса: https://vadym-gr.github.io/Coffee-Shop-Landingpage/. Push у main
запускає деплой; також доступний workflow_dispatch. Ця локальна реалізація сама
по собі не означає, що зміни вже опубліковані.

Файли README іншими мовами й каталог assets залишилися довідковими матеріалами
початкового GoIT-шаблону; поточну реалізацію описує цей README.
